If it only fails on CI and you know which race, commit a "DEBUG -" commit that logs and widens it, and stop with state "needs a try repro": the factory pushes it, with the folder's others, once the user approves, and resumes you with the results. If you can't reproduce it, stop with state "not reproduced" and say what you tried. Run builds and tests in the foreground and wait for them: your session ends when you stop, and anything still running in the background is lost. Write artifacts/evidence.md (what shows the cause, and why the fix belongs where it is) and artifacts/reproduction.md (how to reproduce it, how often it failed with and without the fix), plus artifacts/reproduction.diff if you widened the race. End with the JSON report: state, cause, the kinds of evidence (a guess from reading code says so), the reproduction, those files, how you verified the fix, a bug draft (bug-filing skill) if one is needed, and any patch yours must land after.
